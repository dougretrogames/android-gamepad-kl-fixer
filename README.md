## Visão Geral

O Android mapeia as entradas de gamepads usando arquivos KeyLayout (`.kl`) armazenados em:
```
/system/usr/keylayout/Vendor_XXXX_Product_XXXX.kl
```
Quando um gamepad possui mapeamentos incorretos ou ausentes, os botões podem estar trocados, sem resposta ou reportar códigos de tecla errados. Este app:

1. **Detecta** todos os gamepads conectados via API `InputDevice`.
2. **Captura** dados em tempo real de `KeyEvent` e `MotionEvent` do dispositivo físico.
3. **Gera** um arquivo `.kl` personalizado a partir dos dados capturados.
4. **Instala** o arquivo usando root (`su`) — com backup automático.

## Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 🔍 Escaneamento | Lista todos os dispositivos `SOURCE_GAMEPAD` e `SOURCE_JOYSTICK` |
| 🪪 Diagnóstico | Mostra Vendor ID, Product ID, descritor e máscara de fontes |
| ⌨️ Captura de Key | Captura `keyCode` e `scanCode` em tempo real |
| 🕹️ Captura de Motion | Mostra valores de eixos (sticks, gatilhos) ao vivo |
| 📄 Geração de KL | Gera o arquivo a partir de mapeamentos padrão ou capturados |
| 🔐 Verificação de Root | Verifica o `su` na abertura e avisa se não estiver disponível |
| ⬆️ Instalação | Remonta `/system` como RW, copia e define permissões 644 |
| 🌍 Multilíngue | Suporte para PT-BR, PT-PT, ES e EN |
| 📱 Ícone Adaptativo | Ícone moderno compatível com temas dinâmicos (Android 13+) |

## Arquitetura

O projeto segue o padrão **MVVM**:

```
app/
├── model/           # GamepadDevice, KeyEventRecord, MotionEventRecord (Parcelable)
├── device/          # DeviceScanner (API InputDevice)
├── kl/              # KlFileGenerator (Conteúdo) e KlFileStorage (Privado)
├── root/            # RootManager (Comandos su, backup, install)
└── ui/
    ├── MainActivity         → Lista + Verificação inicial de Root
    ├── DeviceDetailActivity → Diagnóstico + Preview do KL
    ├── TestInputActivity    → Captura de inputs ao vivo
    ├── adapter/             → DeviceAdapter, KeyEventAdapter
    └── viewmodel/           → ViewModels para cada tela
```

## Formato de Arquivo KL

```
# KeyLayout file generated by GamepadKLFixer
key 0x130   BUTTON_A   WAKE
key 0x131   BUTTON_B   WAKE
axis ABS_X        X
axis ABS_Y        Y
```

---

## Operações Root

| Operação | Comando (como root) |
|---|---|
| Verificar root | `id` (uid=0) |
| Instalar | `mount -o remount,rw /system` → `cp` → `chmod 644` → `mount -o remount,ro /system` |
| Backup | `cp Vendor_X.kl Vendor_X.kl.bak` |

- Gamepad USB ou Bluetooth.

## Overview

Android maps gamepad inputs using KeyLayout (`.kl`) files. When mappings are incorrect, buttons may be swapped or unresponsive. This app:

1. **Detects** connected gamepads.
2. **Captures** live `KeyEvent` and `MotionEvent` data.
3. **Generates** a custom `.kl` file.
4. **Installs** the file using root (`su`).

---

## Features

| Feature | Description |
|---|---|
| 🔍 Scanning | Lists all `SOURCE_GAMEPAD` and `SOURCE_JOYSTICK` devices |
| 🪪 Diagnostics | Shows Vendor ID, Product ID, and source bitmask |
| ⌨️ Key Capture | Captures `keyCode` and `scanCode` in real time |
| 🕹️ Motion Capture | Live display of axis values (sticks, triggers) |
| 📄 KL Generation | Generates content from default or captured data |
| 🔐 Root Check | Checks for `su` on startup and warns if unavailable |
| ⬆️ Install | Remounts `/system` RW, copies and sets 644 permissions |
| 🌍 Multilingual | Support for PT-BR, PT-PT, ES, and EN |
| 📱 Adaptive Icon | Modern icon compatible with themed icons (Android 13+) |
